# Портфолио Артемия Бражникова

Лёгкий статический одностраничный сайт: semantic HTML, CSS и небольшой JS-слой для навигации. Для сборки и локального просмотра Node.js не нужен.

## Локальный просмотр

Из корня проекта выполните:

```bash
cd portfolio-site
python3 -m http.server 4173
```

Откройте `http://127.0.0.1:4173/` в браузере. Остановить сервер можно сочетанием `Ctrl+C`.

## GitHub Pages

Содержимое этой папки уже является готовым статическим экспортом. Относительные пути к стилям, скрипту и портрету рассчитаны на публикацию как в корне сайта, так и под путём проекта.

Доступны два обычных варианта:

1. Разместить содержимое `portfolio-site` в корне репозитория, выбрать в Settings → Pages публикацию из нужной ветки и корня репозитория.
2. Оставить папку внутри репозитория и настроить GitHub Actions на публикацию именно `portfolio-site` как статического артефакта Pages.

Перед публикацией проверьте список в `PUBLISH_MANIFEST.txt`. Папка `.portfolio-design` с референсами и QA-материалами в экспорт не входит.
