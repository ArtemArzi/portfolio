## Что оценивается по этим материалам

- **Работа с процессом.** В клубе сам вёл операционные задачи; для строительной CRM встречался с заказчиком и уточнял требования.
- **Пользовательский продукт.** Desktop-админка, кабинеты тренера, ученика и родителя, киоск и адаптивные сайты.
- **Интеграции и данные.** Банковский провайдер, YClients, Telegram, Google Sheets, документы и таблицы.
- **Ошибки и проверка результата.** Повторы событий, неизвестный ответ интеграции, конфликт параметров и отдельное подтверждение человеком.
- **Запуск и документация.** Команды проверки, архитектурные границы, ограничения и материалы для передачи.

Подробнее: [как организую работу](docs/working-method.md). В каждом кейсе отделены личный вклад, фактический статус и граница доказательств. Проценты роста и экономии без измерений не заявляются.

## Что доступно без установки

Презентация содержит шесть кейсов, 12 скриншотов CRM и первые экраны живых сайтов. Галерея позволяет открыть отдельный экран или [скачать ZIP](https://artemarzi.github.io/portfolio/jaguar-crm/jaguar-crm-screenshots.zip). Интерактивный пример записи показывает шесть ситуаций без подключения к реальному салону.

## Публичные репозитории

- `Jaguar-CRM-showcase` и `jaguar-finance-bot-showcase` содержат отдельные срезы прикладного кода и тестов без частной истории и рабочих данных.
- `agent-p-showcase` содержит заново написанный разбор и автономный объясняющий пример. Это **не полный исходник agent_p** и не live-агент.
- Исходники строительной CRM, Excel-проекта и сайтов остаются закрытыми; здесь опубликовано описание допустимой части работы.

Скриншоты CRM содержат вымышленные данные. CSV и данные примера AI-записи созданы специально для объяснения. Они не являются клиентскими выгрузками или показателями бизнеса. Реальные платежи в демонстрации CRM отключены.

## Устройство и локальный просмотр

Статический HTML / CSS / JavaScript; без сборки и внешних frontend-зависимостей. Относительные ссылки работают под прежним GitHub Pages путём `/portfolio/`.

```bash
python3 -m http.server 4173
```

Главная: `http://127.0.0.1:4173/`; кейсы: `http://127.0.0.1:4173/projects/`.

| Путь | Назначение |
| --- | --- |
| `index.html`, `styles.css`, `script.js` | Главная портфолио |
| `projects/` | Кейс-презентация и автономный переключатель сценариев |
| `jaguar-crm/` | Прежняя галерея, исходные изображения и ZIP |
| `assets/` | Портрет и скриншоты публичных сайтов |
| `examples/` | Вымышленная таблица и результаты автономного примера |
| `docs/` | Рабочий подход |
| `PUBLISH_MANIFEST.txt` | Явный состав публикации |

Публикация: GitHub Pages из `main`, корень репозитория. Сохраняются адреса главной, `/projects/` и `/jaguar-crm/`. Перед push проверяются состав, ссылки, отсутствие закрытых данных и desktop/mobile-представление.
